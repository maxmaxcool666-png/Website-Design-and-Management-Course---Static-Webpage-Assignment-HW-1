
### **作業名稱：靜態網頁設計（HW-1）**

### 完成網頁連結

[網頁作業](https://maxmaxcool666-png.github.io/Website-Design-and-Management-Course---Static-Webpage-Assignment-HW-1/)

### **教師評語**

- 本作業以「綠遊智行 APP」為主題，展現了極高的專業度，不僅完全符合所有基本規範，在語意化標籤的運用與視覺美感上也表現得非常出色。 放上雲端公開：+10

### 作業目標

- 練習使用基礎 HTML 結構與常用標籤（標頭、段落、清單、表格、多媒體、連結）。
- 能套用基礎 CSS（版面、字體、顏色、間距、邊框、hover）。
- 能在網頁中正確使用 Font Awesome 或 Google Icons。
- 產出一個可獨立瀏覽的「單頁式」靜態網站。

### 主題（擇一）

- 個人簡介／自我介紹
- 社團或活動宣傳頁
- 美食或旅遊推薦頁
- 作品集簡介頁
- 任選主題（需健康、合適、能公開展示不犯法的）

### 繳交內容

- 一個資料夾（建議命名：`HW1_學號_姓名`）內含：
  - `index.html`
  - `styles/style.css`
  - `assets/`（放圖片、音檔、影片等）
- 以壓縮檔（.zip）或分享連結方式繳交

### 網頁必備結構（HTML）

至少包含以下區塊，並在導覽列可快速跳到各區塊：

1. **Header**：網站標題 + 一句標語
2. **Nav 導覽列**：至少 4 個連結（可用錨點 #section）
3. **Main 主要內容**：至少 3 個內容區塊（如 About / Skills / Works / Food / Travel 等）
4. **Footer**：作者資訊 + 版權文字 + 聯絡方式

### 必備元素與規格

#### 1) 文字與排版

- 至少使用：
  - 2 種不同層級的標題（h1～h3 任選）
  - 3 段以上段落（p）
  - 1 個清單（ul 或 ol）
- 至少設定 5 個 CSS 樣式，包含：
  - 字體或字級（font-family / font-size）
  - 顏色（color / background-color）
  - 間距（margin / padding）
  - 邊框或圓角（border / border-radius）
  - hover 效果（例如導覽列連結變色）

#### 2) 表格（table）

- 需有 1 個表格，包含：
  - 表頭（thead 或 th）
  - 至少 3 欄、3 列以上
- 表格需套用基本 CSS（例如邊框、斑馬紋、置中等，擇一即可）。

#### 3) 多媒體（擇一或以上）

- 圖片：至少 2 張（需加上 alt），且至少 1 張使用 CSS 控制大小或圓角
- 影片：可用 `<video>` 或嵌入 YouTube（擇一）
- 音訊：可用 `<audio>`（選做加分）

#### 4) 圖示

- Font Awesome：至少 3 個不同 icon（例如社群、技能、聯絡方式）
- Google Icons：至少 2 個 icon

#### 5) 超連結

- 至少 2 個外部連結（例如 IG、YouTube、GitHub、喜歡的網站）
- 外部連結請開新視窗（target="\_blank"）

### 版面要求（CSS）

- 網頁需有基本一致的視覺風格（配色、字體、間距一致）。
- 需有「容器」概念（例如 `.container` 設定寬度與置中）。
- 不可全部只用預設樣式。

### 檔案與程式碼規範

- HTML 結構需正確包含：`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
- `<head>` 需包含：`<meta charset="UTF-8">` 與 `<title>`
- CSS 請放在 `style.css`，並用 `<link>` 引入
- 需有適當縮排與註解（HTML 或 CSS 擇一即可）

### 評分規準（100 分）

- 結構完整與需求符合（40）
- CSS 基本美編與一致性（30）
- 表格、多媒體、連結、圖示使用正確（20）
- 檔案命名、縮排、可讀性（10）

### 加分項（最多 +10）

- 使用簡單的版面配置（例如兩欄區塊、卡片樣式）
- 自訂配色主題與更好的排版
- 將你的作品放置雲端空間直接上線，但需額外提供你如何將你的作品上線的操作過程說明。（此項就直接多加10分）

### **禁止事項**

- 不可直接複製整個現成模板（可參考但需自行修改並能說明每個區塊用途）。
- 嚴禁使用 AI 直接生成整站程式碼後不理解內容。
